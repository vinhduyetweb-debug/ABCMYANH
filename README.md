
# ABC Adventure V3

Interactive emotional English learning mini app for kids.

## Features
- British English voice
- Emotional mascot
- Fireworks success FX
- Bubble explosion wrong FX
- XP + level system
- Combo system
- Treasure reward
- Sticker collection
- Mobile-first UI
- Offline ready

## Run Local
Open index.html

## Deploy
Upload directly to Vercel or Netlify.
